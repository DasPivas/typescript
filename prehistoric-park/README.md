# Первобытный парк — мобильный ремейк

Парко-строительный тайкун про первобытное племя: тянем дороги, ставим аттракционы,
кормим и поим гостей, следим за настроением и балансом. Ремейк J2ME-игры
«Первобытный парк» (Gear Games, 2007) для смартфона: вертикальный экран,
тач-управление, HTML5.

Стек выбран с прицелом на рост: **TypeScript + PixiJS 8 + Vite**, вся симуляция —
чистый TS без зависимостей от рендера, поэтому её можно тестировать отдельно,
а обёртку в нативное приложение (Capacitor → iOS/Android) добавить позже без
переписывания логики.

## Запуск

```bash
npm install
npm run dev      # откроется на http://localhost:5173, --host уже включён
npm run build    # прод-сборка в dist/
npm run preview  # посмотреть собранное
```

Чтобы поиграть с телефона в одной Wi-Fi-сети: `npm run dev` и открыть
`http://<ip-компьютера>:5173`. На iPhone удобно добавить страницу на домашний экран —
она откроется без адресной строки.

## Управление

| Действие | Жест |
| --- | --- |
| Двигать карту | один палец |
| Приближать | щипок двумя пальцами |
| Поставить постройку | тап — примерить, тап по той же клетке — поставить |
| Проложить дорогу | выбрать дорогу и вести пальцем |
| Открыть карточку объекта | тап по нему (когда ничего не выбрано) |
| Пройти обучение | «уровни» → «обучение» |
| Повернуть вход | кнопка ⟳ на плашке выбранной постройки |

## Что уже работает

- **Карта** 26×34 клетки с травой, водой и скалами, генерится по сиду уровня.
- **Дороги** двух типов; посетители ходят только по ним, поиск пути — волна по
  дорожному графу.
- **Постройки:** 8 аттракционов, 6 сервисов, диномотор с зоной покрытия,
  5 видов декора. У аттракционов **раздельные вход и выход** — обе клетки обязаны
  примыкать к дороге, это и есть основная головоломка планировки. Вход помечен
  светлой рамкой со стрелкой внутрь, выход — зелёной со стрелкой наружу.
- **Посетители:** голод, жажда, туалет, усталость, здоровье и скука; настроение
  считается из потребностей, цен и окружения. Иконка над головой показывает желание.
  Злой гость уходит и может устроить драку.
- **Экономика:** билеты с настраиваемой ценой и «честной ценой» по рейтингу,
  зарплаты и обслуживание в новолуние, банкротство за три месяца в минусе.
- **Работники:** повар, продавец, шаман — в здании; ремонтник и охранник — по парку,
  сами ищут поломки и драки.
- **Очереди** выстраиваются лентой вдоль дороги и подтягиваются, когда кого-то
  посадили. Простоял больше минуты — уходит недовольным.
- **Анимации:** крутится карусель и колесо, качаются качели и тарзанка, прыгает
  батут, едет вагонетка на горках, вращается шестерня диномотора, круги на воде
  у источника. Аттракцион оживает, только когда внутри есть гости.
- **Звук** целиком синтезируется в WebAudio: барабан, бас и дудка по пентатонике
  плюс эффекты постройки, кассы, поломки и катания. Спрашивается при первом
  запуске, переключается в меню.
- **Обучение** из семи шагов (дорога → аттракционы → еда и вода → работник →
  скамейки → охранник → свобода), шаг закрывается сам по выполнении.
- **Износ и поломки** аттракционов.
- **5 уровней кампании** (равнина, динозавры, мамонты, плато, врата рая) с целями
  и постепенно открывающимися постройками + свободная игра.
- Сохранение в localStorage, статистика, помощь, три скорости времени.

## Структура

```
src/
  core/       чистая симуляция, не знает про Pixi и DOM
    types.ts      сущности
    catalog.ts    справочник построек и работников (баланс правится здесь)
    levels.ts     уровни и условия победы
    grid.ts       карта, размещение, поворот, зоны декора и диномотора
    path.ts       волна по дорогам
    game.ts       игровой цикл: посетители, здания, работники, экономика
    tutorial.ts   шаги обучения и их условия
  render/     Pixi: процедурная графика, сцена, камера, жесты
    art.ts        все спрайты и кадры анимации рисуются кодом
  audio/      синтез музыки и эффектов на WebAudio
  ui/         DOM-интерфейс поверх канваса
```

Вся графика генерируется кодом в `render/art.ts` — никаких файлов из оригинальной
игры в репозитории нет. Названия объектов и механики взяты из оригинала,
рисовка своя.
