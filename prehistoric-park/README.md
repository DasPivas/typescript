# Первобытный парк — мобильный ремейк

Парко-строительный тайкун про первобытное племя: тянем дороги, ставим аттракционы,
кормим и поим гостей, следим за настроением и балансом. Ремейк J2ME-игры
«Первобытный парк» (Gear Games, 2007) для смартфона: вертикальный экран,
тач-управление, HTML5, устанавливается на домашний экран как приложение.

Стек: **TypeScript + PixiJS 8 + Vite**. Симуляция — чистый TS без зависимостей от
рендера, поэтому она покрыта тестами и переживёт любую смену обёртки: браузер,
PWA, Capacitor.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173, --host уже включён
npm run build    # прод-сборка в dist/
npm run preview  # посмотреть собранное
npm test         # тесты симуляции
npm run icons    # перегенерировать иконки PWA
```

Поиграть с телефона в одной Wi-Fi-сети: `npm run dev` и открыть
`http://<ip-компьютера>:5173`. На iPhone — «Поделиться» → «На экран Домой»:
игра откроется во весь экран и будет работать офлайн.

### Нативное приложение

Конфиг Capacitor лежит в `capacitor.config.ts`, нативные проекты в репозитории
не хранятся — они генерируются локально:

```bash
npm run cap:add:ios      # нужен macOS + Xcode
npm run cap:add:android  # нужен Android Studio
npm run cap:sync         # собрать веб и залить в нативный проект
```

## Управление

| Действие | Жест |
| --- | --- |
| Двигать карту | один палец |
| Приближать | щипок двумя пальцами |
| Поставить постройку | тап — примерить, тап по той же клетке — поставить |
| Проложить дорогу | выбрать дорогу и вести пальцем |
| Открыть карточку объекта | тап по нему (когда ничего не выбрано) |
| Повернуть вход | кнопка ⟳ на плашке выбранной постройки |
| Скорость времени | ❚❚ / ▶ / ▶▶ / ⏩ справа внизу |

## Что уже работает

**Карта и стройка**
- 26×34 клетки с травой, водой и скалами, генерация по сиду уровня.
- Дороги двух типов; гости ходят только по ним, поиск пути — волна по дорожному графу.
- 15 аттракционов, 6 сервисов, диномотор, указатели и 5 видов декора.
- У аттракционов **раздельные вход и выход** — обе клетки обязаны примыкать к дороге.
  Вход помечен светлой рамкой со стрелкой внутрь, выход — зелёной со стрелкой наружу.
- Особые требования: шестерёнка — только в зоне диномотора, водные аттракционы —
  только вплотную к воде.
- **Указатели**: рядом с ними гости «видят» парк вдвое дальше, без них дальние
  постройки просто не находят.

**Люди**
- Три типа гостей: дети, взрослые и старики — разный кошелёк, скорость, терпение
  в очереди и допустимая бодрость аттракционов.
- Потребности: голод, жажда, туалет, усталость, здоровье и скука; настроение
  считается из потребностей, цен, погоды и окружения. Иконка над головой показывает желание.
- Очереди выстраиваются лентой вдоль дороги; простоял дольше терпения — уходит недовольным.
- На скамейках гости сидят, и это видно.
- Злой гость уходит и может устроить драку — её разгоняет охранник.

**Экономика и время**
- Билеты с настраиваемой ценой и «честной ценой» по рейтингу.
- Зарплаты и обслуживание в новолуние, банкротство за три месяца в минусе.
- **Сезоны и погода**: дождь режет приток вдвое, жара утраивает жажду, холод гонит
  гостей по домам. Погода видна в шапке и на экране.
- **Изобретения**: часть аттракционов открывается по ходу уровня, а не выдаётся сразу.
- Офлайн-доход: пока игра закрыта, парк работает сам (четверть обычного, не больше 8 часов).

**Прогресс**
- 12 уровней кампании, открываются по очереди, за каждый — до трёх звёзд.
- 10 долгих заданий и таблица рекордов.
- Обучение из семи шагов, шаг закрывается сам по выполнении.
- Сохранение в IndexedDB (с откатом на localStorage), автосохранение раз в полминуты.

**Оформление**
- Вся графика рисуется кодом, включая кадры анимации: крутятся карусель и колесо,
  качаются качели и тарзанка, прыгает батут, едут вагонетки, летит прыгун с вышки,
  плывёт лодка по водной дорожке.
- Звук синтезируется в WebAudio: барабан, бас и дудка по пентатонике плюс эффекты.
- PWA: манифест, иконки, сервис-воркер — игра ставится на домашний экран и работает офлайн.

## Структура

```
src/
  core/       чистая симуляция, не знает про Pixi и DOM
    types.ts        сущности
    catalog.ts      справочник построек и работников (баланс правится здесь)
    levels.ts       12 уровней, изобретения, условия победы
    grid.ts         карта, размещение, повороты, зоны декора/мотора/указателей
    path.ts         волна по дорогам
    buildings.ts    очереди, посадка, износ, поломки
    visitors.ts     потребности, настроение, выбор цели, ходьба
    staffAI.ts      ремонтник и охранник
    weather.ts      сезоны, погода и их влияние
    game.ts         оркестратор: состояние, цикл, экономика, цели
    achievements.ts долгие задания
    save.ts         IndexedDB, профиль, офлайн-доход
    tutorial.ts     шаги обучения
  render/     Pixi: процедурная графика, сцена, камера, жесты, погода
  audio/      синтез музыки и эффектов
  ui/         DOM-интерфейс поверх канваса
  __tests__/  тесты симуляции (vitest)
```

Никаких файлов из оригинальной игры в репозитории нет: названия объектов и
механики взяты из оригинала, вся графика и звук — свои.
